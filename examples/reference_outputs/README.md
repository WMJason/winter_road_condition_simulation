# Synthetic Example Outputs

These files come from `examples/synthetic_demo.py --seed 42`, using Python 3.10.7 and the dependencies in `requirements-tested.txt` on macOS. They contain no real RWIS observations and are not evidence for the Iowa findings.

The example produced three synthetic groups and three realizations for each selected parent, giving nine small simulated fields. Only a preview figure, clustering diagnostic, map-summary CSV, and completion report are retained here. Run the demo to generate its complete small output set in the ignored `examples/generated/` directory.
